# GPU install

The Python environment must get a CUDA-enabled PyTorch build first. Do **not** rely on the generic `pip install torch` line if you specifically want CUDA.

Use the official PyTorch installer selector for your OS, Python, and CUDA choice, then install this project's requirements.

## Windows 10/11 PowerShell

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
python -m pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
python -m pip install -r requirements-portable.txt
python check_gpu.py
```

## Linux bash

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -U pip
# Install the CUDA-enabled PyTorch command generated by the official PyTorch selector here.
python -m pip install -r requirements-portable.txt
python check_gpu.py
```

## Run the engine

```bash
python legal_rag_engine.py --documents "legal_documents.json" --output artifacts_portable
```

For more VRAM:

```bash
python legal_rag_engine.py --dense-batch-size 64 --rerank-batch-size 64
```

For less VRAM:

```bash
python legal_rag_engine.py --dense-batch-size 8 --rerank-batch-size 8 --precision fp16
```

For a first speed benchmark, keep `--compile-reranker` OFF. After the baseline is stable, benchmark again with it enabled.
